## Quick start (students)

```bash
npx create-expo-app@latest HelloWorld
cd HelloWorld
npm run reset-project        # answer "n" to delete the demo
# replace src/app/index.tsx with code/hello-world/index.tsx
npx expo start               # scan the QR code with Expo Go, or press "a" for the Android Emulator
```
